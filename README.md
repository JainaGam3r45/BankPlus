# BankPlus

After years of modelling, improving and adding suggestions, this is what bankplus became today, the best bank plugin on the market ever made, full of features, fully customizable with the most efficient code possible.

<p align="center">
  <a href="https://discord.gg/tanHjMv7hY"><img src="https://github.com/user-attachments/assets/58e41212-d98e-41bd-9bdf-081d5549330d" alt="Discord"></a>
</p>

Support will be only given on discord.
Do not use the review section to report bugs, ask questions or leave suggestions.

Make sure to check the [wiki](https://github.com/Pulsih/BankPlus/wiki)!

# **Plugin requirements**
1. [Vault](https://www.spigotmc.org/resources/34315/) (Economy Hook)
2. Economy Plugin (For example [EssentialsX](https://essentialsx.net/downloads) or one of the listed plugins on the Vault page)

_Without these 2 requirements, BankPlus won't start._

# **Plugin optional requirements**
1. [PlaceholderAPI](https://www.spigotmc.org/resources/6245/) (Displays placeholders in the gui and shows BankPlus placeholders)

## Features

<p align="center">
  <img src="https://github.com/user-attachments/assets/bda13791-8355-44be-8e1a-4f55adb4da60" alt="Features" width="720">
</p>

- Built-in GUI system.
- Unlimited amount of banks.
- MySQL support.
- GUI with custom heads & custom model data items support.
- Interest system, both online and offline.
- Actions followed by sound effects.
- Various ways to deposit / withdraw money.
- BankTop fully customizable.
- Bank upgrades with cost and custom items.
- Transaction taxes.
- Loan system with debts.
- Efficient code, every resource is used with efficiency and lightweight in mind.
- Complete wiki.
- Much much more..

If you want to test the plugin, you can join on our test server **pulsi.jifercraft.com** *(Soon...)* that is hosted thanks to [JiferCloud Hosting](https://www.jifercraft.com/)!
